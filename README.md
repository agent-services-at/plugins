# EmpCo-UWG Monitor – Plugin-Marketplace

Dieses Repository enthält ausschließlich das gebaute Plugin „EmpCo-UWG Monitor" (Version 1.0.0) für Anwendungen mit Plugin-Unterstützung (getestet und empfohlen mit Claude und ChatGPT, einschließlich Codex) und wird bei jedem Release automatisch befüllt. Änderungen hier werden überschrieben.

Zum Verwenden ist ein Zugangscode (Lizenz) nötig, der bei der Anmeldung der Verbindung eingegeben wird.

## Installation

- **Claude (Desktop-App, Cowork) und ChatGPT (Desktop-App, Codex):** Marketplace in der Plugin-Verwaltung hinzufügen und `tobias-zucali/EmpCo-UWG-Monitor-Plugin` angeben (Schritte in der Anleitung).

Als Rückfall steht dasselbe Paket als Zip-Datei bereit: [empco-uwg-monitor-plugin.zip](https://github.com/tobias-zucali/EmpCo-UWG-Monitor-Plugin/releases/latest/download/empco-uwg-monitor-plugin.zip) (Upload-Schritte siehe Anleitung).

Die vollständige Anleitung zu Anmeldung, Aktualisierung und Fehlerhilfe je Anwendung liegt im Plugin: [skills/report-green-claims/references/setup.md](skills/report-green-claims/references/setup.md). Die aktuelle Fassung steht unter https://claims.agent-services.at/einrichtung.
